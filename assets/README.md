# RIFT visual assets

`branding/` contains the original RIFT mark and brand reference files.
`visuals/` contains original, repository-relative SVG illustrations used by the
visual-first README and documentation. They use the dark technical grid,
electric-green primary accent, and cyan secondary accent defined for this
experience; no stock imagery or third-party logos are used.

`screenshots/` is reserved for verified runtime captures. Mockups and
illustrations must never be labeled as screenshots.
