# Security policy

## Scope

RIFT is a local-first retrieval server. It does not execute retrieved
commands or provide arbitrary shell access. The streamable HTTP endpoint is
unauthenticated and must remain on localhost unless an operator supplies
external authentication, authorization, network controls, and TLS.

## Reporting a vulnerability

Please report security issues privately to the repository maintainer through a
GitHub security advisory or private maintainer contact. Do not include
credentials, live target data, or undisclosed exploit details in public issues.
Provide the affected version or commit, reproduction steps using a disposable
fixture, impact, and any suggested mitigation.

There is no supported SLA until a maintainer security contact and disclosure
process are formally established.
