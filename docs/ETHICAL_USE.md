# Ethical use

Use RIFT only for systems, accounts, and datasets you own or for which you
have explicit written authorization. It is intended for defensive testing,
security education, authorized penetration testing, detection engineering,
DFIR, and security research.

Do not use it to gain unauthorized access, steal credentials, exfiltrate data,
deploy malware, evade controls, disrupt services, or target people or
organizations without permission. The knowledge base is extractive reference
material and may contain unsafe or target-specific examples; retrieval is not
endorsement, validation, or authorization.

No license has been selected for this repository. Until licensing and dataset
rights are explicitly established, treat all project and bundled data rights
as reserved.
